## Admin post-type manager
The same CMS powers all six requested post types:
- Gadgets
- Jersey
- Fashion
- Articles
- Docs
- Pages

Each type supports title, slug, excerpt, content/HTML, status, visibility, category, tags, featured flag, cover image, SEO title, SEO description, SEO keywords and schema type.

Bulk actions:
- Publish
- Draft
- Private
- Assign tag
- Assign category
- Delete
